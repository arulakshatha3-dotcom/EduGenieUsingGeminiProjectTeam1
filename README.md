# 🎓 EduGenie – Google Gemini Powered Learning Assistant

EduGenie is an AI-powered educational learning assistant designed to help students learn effectively using generative AI.

## ✨ Features

- 🤖 Question & Answer
- 📚 Explain a Concept
- 📝 Generate Quiz
- 📄 Summarize Text
- 🛤️ Personalized Learning Path
- 🌐 Simple and responsive web interface
- ⚡ FastAPI backend
- 🔗 Google Gemini API integration
